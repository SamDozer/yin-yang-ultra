# الوجود الفائق — تجربة الين واليانج الكونية
# Yin-Yang Cosmic Genesis & Interactive Harmony Sandbox

محاكاة بصرية وصوتية وفيزيائية فائقة الدقة لفلسفة **الين واليانج (Yin & Yang)** وحفظ الطاقة والتوازن في الوجود، مبنية بالكامل باستخدام **HTML5 Canvas** و **Web Audio API** بدون أي مكتبات أو اعتماديات خارجية (Pure Vanilla JS).

---

## 🌟 الأنماط الرئيسية (Main Modes)

### 1. ♾ نمط الدورة الكونية الأبدية (Infinite Cosmic Cycle)
دورة سينمائية متجددة بلا انقطاع مدتها 24 ثانية تعبر عن الأزلية الكونية:
- **0.0s - 6.0s (تجمع الطاقة المعكوسة):** انبثاق البذرتين في لولبيات طاقة واردة تجتذب كل بذرة نقيضها.
- **6.0s - 9.0s (التقارب والاندماج الأبدي):** تقارب الكتلتين في دوامة مهيبة حتى التمازج التام مصحوباً برنين كاسات التيبت الكونية (Tibetan Singing Bowl Chimes).
- **9.0s - 13.5s (كمال التوازن ثم تصاعد الإجهاد):** دوران متناغم يتصاعد فيه التوتر والإجهاد الكهرومغناطيسي.
- **13.5s (الانفجار الكوني الهائل):** دوي انفجار رعدي عميق (Sub-bass Mega Boom) وانشطار الكتلتين مع موجات صدمة متوسعة وتفتت الحواف.
- **18.5s - 24.0s (الاستدارة والتجاذب السلس):** تتباطأ جزيئات الطاقة عند أقصى المدى الكوني وتستدير بنعومة بالغة لتتجاذب من جديد نحو موقع البذور لتبدأ الدورة التالية بسلاسة تامة وانعدام أي تقطيع بصري.

### 2. 🎛 نمط المختبر التفاعلي المستقر (Stable Sandbox Mode)
تحكم حي ومباشر في مقادير الين واليانج مع تطبيق القوانين الفيزيائية لحظياً:
- **سلايدرات حية لطاقتي الين واليانج (0 - 30)** مع أزرار الزيادة والنقصان السريع (+2 / -2).
- **مؤشر التناغم الكوني الحي (Live Harmony Gauge):** قياس نسبة الاتزان التناغمي (0% - 100%) بألوان ديناميكية.
- **أوضاع كونية مسبقة (Presets):**
  - ☯ اتزان مقدس (12 : 12)
  - 🌑 طغيان الين (22 : 6)
  - 🌕 طغيان اليانج (6 : 22)
  - ⚡ حمل فائق (26 : 26)
  - 💥 تمزق وانفجار (30 : 1)
  - 🌀 سكون الفراغ (3 : 3)
- **ميزة التناغم الذاتي (Auto-Harmonize):** تكيّف ذاتي تلقائي يستعيد التوازن بين الطرفين بمرور الوقت.
- **نظام التمزق الحرج (Critical Rupture):** عند تجاوز الإجهاد 95% ينفجر النظام سينمائياً مع شحنات برق وموجات صدمة متتالية، مع زر استعادة فوري للاتزان.

## 🎨 المؤثرات البصرية والصوتية

- **هندسة مقدسة دائرية 100%:** قص دائري دقيق ومحكم يضمن انسيابية الشكل الطبيعي للين واليانج.
- **حلقات مجال الطاقة الكونية:** 3 حلقات متحدة المركز تهتز بنعومة وتتحول ألوانها من السماوي إلى الذهبي ثم الأحمر حسب الإجهاد.
- **جزيئات مدارية ذات ذيول متوهجة:** 64 جزيء في 3 مدارات فضائية تتسع وتتسارع مع الطاقة.
- **مسارات تدفق طاقية داخلية:** خطوط انسيابية منحنية تربط القطبين تلتوي وتتموج مع تغير التكافؤ.
- **هالة التنفس الكونية:** نبض دوري هادئ يتنفس مع الاتزان ويتوتر مع الإجهاد.
- **بريق التناغم الماسي:** نجوم ماسية وضاءة تتلألأ حول الدائرة عند بلوغ التناغم الفائق.
- **صوت إجرائي متكيف (Web Audio API):** نغمات Drone متغيرة، رياح كونية، طقطقة إجهاد كهربائي، وانفجار ساب-باس رعدي خالص بدون ملفات صوت مسجلة.

## 🚀 طريقة التشغيل (Quick Start)

### التشغيل المباشر بدون إنترنت:
- انقر نقراً مزدوجاً على ملف **`standalone.html`** أو **`launch.bat`** ليفتح في أي متصفح مباشرة.

### أو عبر خادم محلي (Local Web Server):
```bash
python -m http.server 8000
```
ثم افتح: `http://localhost:8000/index.html` في متصفحك.

## 📁 هيكلية المشروع (Project Structure)

```
├── standalone.html       # نسخة مجمعة قائمة بذاتها بنقرة واحدة (Self-contained)
├── launch.bat            # ملف تشغيل سريع لنظام ويندوز
├── index.html            # الصفحة الرئيسية المعيارية
├── style.css             # تصميم الواجهة الفضائية الزجاجية (Cyber-Zen HUD)
├── app.js                # منسق التطبيق والأنماط والأحداث
├── engine.js             # محرك الفيزياء وقوانين الطاقة والاتزان
├── motion.js             # الحسابات الهندسية ومسارات الجزيئات
├── renderer.js           # محرك الرسوم البصرية (Canvas 2D Engine)
├── audio.js              # محرك الصوت الإجرائي الفضائي (Web Audio API)
├── build_standalone.py   # أداة تجميع وتحديث الملف المستقل
└── README.md             # وثيقة المشروع
```
