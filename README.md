# الين واليانج — رحلة · Yin-Yang Journey

رحلة تأمّلية بصرية وصوتية في الين واليانج، مبنية بـ **HTML5 Canvas** و **Web Audio** بلا أي مكتبات.
*A contemplative, dependency-free visual and audio journey through yin and yang, using classical texts.*

## الحركات الخمس · The five movements

| # | الحركة | ما تراه | المصدر |
|---|---|---|---|
| 1 | 無極 اللاقطب | دائرة فارغة وقطرة ضوء تسقط | 太極圖說 |
| 2 | 太極 القطب الأعظم | تدور الدائرة ثم تسكن وتنفتح | 太極圖說 |
| 3 | 兩儀四象 الصورتان والصور الأربع | أربعة أطوار حول العجلة: اليانغ والين الناشئ والأعظم | 易經 · 繫辭上 |
| 4 | 物極必反 الانقلاب | الغلوّ يتحوّل إلى نقيضه بدل أن ينكسر | 道德經 ٤٠ |
| 5 | 歸 العودة | دورة 24 ثانية بحلقة الحدود الشمسية الأربعة والعشرين وكوا يتبدل | 易經 · 道德經 ٤٢ |

بعدها **الممارسة**: مختبر تفاعلي مع **無為** (الوو وي) — دع يديك فيعود الاتزان وحده.

- **تأمّل / دراسة** — *Contemplate / Study*: تأمّل يُظهر الصورة فقط؛ دراسة تُظهر النص الصيني والترجمة والمصدر والتعليق.
- **الانقلاب لا الانفجار**: الاختلال المستمر ينقلب إلى نقيضه؛ لا ينفجر إلا الحمل الزائد (المجموع نحو 36 وحدة فأكثر) أو الفراغ شبه التام.
- **الصوت**: نغمات خماسية؛ الاتزان خامسة تامة (3:2) والاختلال يولّد ارتجاجاً. يبدأ بعد أول نقرة.

## التشغيل · Running

- انقر `launch.bat` أو افتح `standalone.html` (يعمل دون إنترنت).
- أو: `python -m http.server 8000` ثم افتح `http://localhost:8000/index.html`.
- الاختبارات: `npm test` (Node ≥ 20، دون تبعيات) و `npm run check:quotes`.
- إعادة بناء الملف المستقل: `python build_standalone.py`.
- الخطوط: `python tools/subset_fonts.py` يولّد `fonts.css` بمجموعات جزئية من خطّي Ma Shan Zheng و Amiri (رخصة SIL OFL)؛ إن كان `fonts.css` فارغاً تُستخدم خطوط النظام.

## البنية · Structure

| الملف | الدور |
|---|---|
| `engine.js` | قوانين الإجهاد، الانقلاب، الطور الرباعي، دورة العودة |
| `hexagram.js` | من الاتزان إلى الكوا (الاثنا عشر الحاكمة) |
| `texts.js` | المقاطع والمصادر (بيانات فقط) |
| `journey.js` | الحركات الخمس وتوقيتها ومشاهدها |
| `tuning.js`, `audio.js` | السلّم الخماسي والصوت الإجرائي |
| `renderer.js` | رسم الحبر والضباب والحلقات والكوا |
| `app.js`, `index.html`, `style.css` | الواجهة والتحكم |
| `tests/` | اختبارات الوحدات |
